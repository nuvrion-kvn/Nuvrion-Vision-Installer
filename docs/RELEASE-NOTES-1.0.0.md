# Nuvrion Vision Installer 1.0.0

Развёртывание выделенной Remnawave-ноды с VLESS, TLS 1.3, XTLS Vision и автономным HTTPS-сайтом PokéHabitat.

- RemnaNode в Docker с закреплением загруженного образа по digest; Xray принимает подключения на TCP/443.
- VPN-подключения обрабатываются VLESS; обычный HTTPS передаётся nginx через Unix-сокеты HTTP/1.1 и HTTP/2.
- Локальные интерфейс, изображения, игровой API и SQLite; игровые службы работают без внешних API и CDN.
- Сертификат Let's Encrypt, проверка продления и автоматическое обслуживание; TCP/80 открывается на время ACME.
- Встроенный Auto Tuning, UFW, Fail2ban, настройка SSH и ограничения API адресами панели; Traffic Control по согласию.
- Проверка компонентов, вывод профиля для панели, сохранённый менеджер `--resume` / `--check` и атомарная запись проекта.

Документация включает подробные светлые схемы установки, сетевых маршрутов, настройки сервера и фильтрации трафика. Контакты Telegram и email автора удалены из документации, меню и встроенных компонентов. Для вопросов и ошибок используется GitHub.

Файлы для установки: `nuvrion-vision-install.sh` и `SHA256SUMS`. Версия установщика и встроенных компонентов — **1.0.0**. Сборка автономного архива воспроизводима; контрольные суммы проверяются перед упаковкой.

Требуется чистый отдельный сервер. Готовый профиль нужно применить в панели Remnawave: код `2` означает ожидание профиля TLS/443, код `0` — успешную локальную проверку. Уже установленные ноды автоматически не обновляются.
