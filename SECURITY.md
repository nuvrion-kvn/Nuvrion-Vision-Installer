# Безопасность

Никогда не публикуйте `SECRET_KEY`, `/opt/remnanode/node.env`, приватные ключи сертификатов, токены панели или диагностические материалы с этими значениями.

Перед обращением выполните:

```bash
bash /opt/remnanode/installer.sh --check
ntc check
```

Команды не выводят секретный ключ. Для сообщений об уязвимостях используйте GitHub. Укажите версию, условия воспроизведения и влияние; рабочие секреты и эксплойты не размещайте в публичном Issue.

Если в разделе Security доступна кнопка **Report a vulnerability**, отправьте закрытый отчёт через неё. Иначе создайте Issue только с общим описанием проблемы; не публикуйте секреты, рабочий эксплойт и данные чужих серверов.
