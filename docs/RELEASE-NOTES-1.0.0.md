# Nuvrion Vision Installer 1.0.0

Первый выпуск под брендом Nuvrion с новой историей репозитория.

Развёртывание Remnawave-ноды с TLS Vision и HTTPS-сайтом.

- Скрипты, службы, пути и переменные окружения используют имя Nuvrion.
- Версия самостоятельного скрипта и встроенных компонентов — 1.0.0.
- Обновлены описание, инструкции запуска, баннер и схемы работы.
- Контрольные суммы поставляются рядом со скриптом в SHA256SUMS.
- Лицензии сторонних компонентов сохранены.

Инструкции установки и ограничения: [README.md](../README.md).
